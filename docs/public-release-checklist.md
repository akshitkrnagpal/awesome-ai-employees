# Public Release Checklist

Keep the repository private until these checks are complete.

## Repository

- [ ] `make check` passes locally.
- [ ] GitHub Actions `Check` workflow passes on `main`.
- [ ] Repository description is concise and accurate.
- [ ] Repository topics include `awesome-list`, `ai-agents`, `ai-employees`, and related discovery terms.
- [ ] Issues are enabled.
- [ ] Wiki is disabled.
- [ ] License is intentional for the curated list.

## Content

- [ ] README explains what counts as an AI employee or digital worker.
- [ ] Every company has a public evidence URL.
- [ ] Links do not include tracking or affiliate parameters.
- [ ] Categories and counts are generated from `data/companies.csv`.
- [ ] `data/companies.json` is generated from the CSV.
- [ ] Submission rules are clear in `CONTRIBUTING.md`.

## Manual GitHub Steps

- [ ] Review the rendered README on GitHub.
- [ ] Confirm issue templates render correctly.
- [ ] Set a repository social preview image if desired.
- [ ] Change visibility to public when ready.
