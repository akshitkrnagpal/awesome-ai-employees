# Quality Scorecard

This repo is considered ready for a wider public release when every item below is true.

## 10/10 Criteria

- [x] The README explains the category and inclusion rules clearly.
- [x] The company list has one source of truth: `data/companies.csv`.
- [x] README listing sections are generated from the CSV.
- [x] JSON data is generated from the CSV.
- [x] Local commands exist for generation and verification.
- [x] GitHub Actions verifies generated artifacts on push and pull request.
- [x] Contribution rules explain what belongs and what does not.
- [x] Issue and pull request templates guide submissions.
- [x] The repository has an explicit license.
- [x] The repository has a manual public-release checklist.

## Manual Review Before Public Launch

These are intentionally left for the maintainer because they require product judgment:

- [ ] Re-check each evidence URL in the rendered README.
- [ ] Confirm every listing still matches the current public positioning.
- [ ] Decide whether to add more fields such as `role_name`, `customer_type`, `autonomy_level`, or `pricing_public`.
- [ ] Decide whether to add a social preview image.
